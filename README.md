# E-commerce Food – Cardápio Digital

Aplicação de e-commerce voltada para pedidos de comida, desenvolvida com **C# e Blazor**. O projeto simula a experiência de um cardápio digital, permitindo navegar pelos produtos, adicionar itens ao carrinho e acompanhar o processo de pedido.

## Tecnologias

- **C#** – Linguagem principal.
- **.NET 9** – Plataforma de desenvolvimento.
- **Blazor** – Construção da interface web interativa.
- **MudBlazor** – Biblioteca de componentes visuais para Blazor.

## Funcionalidades

- **Cardápio digital:** Exibição e navegação pelos produtos disponíveis.
- **Carrinho de compras:** Gerenciamento dos itens selecionados.
- **Interface interativa:** Componentes dinâmicos e atualizações de estado.
- **Experiência responsiva:** Adaptação da interface para diferentes tamanhos de tela.
- **Fluxo de pedidos:** Simulação das etapas de um pedido.

## Organização do projeto

| Diretório | Responsabilidade |
|---|---|
| `Components/` | Componentes e páginas da aplicação Blazor. |
| `Entities/` | Entidades e modelos utilizados no projeto. |
| `Services/` | Serviços responsáveis pelas regras e gerenciamento de estado. |
| `Utils/` | Classes e funcionalidades auxiliares. |
| `wwwroot/` | Arquivos estáticos, estilos e recursos visuais. |

## Executando o projeto

**Pré-requisitos:**
- .NET 9 SDK

Clone o repositório:

```console
git clone https://github.com/Pilatii/ecommerce-food-blazor.git
```

Entre no diretório:

```console
cd ecommerce-food-blazor
```

Restaure as dependências:

```console
dotnet restore
```

Execute a aplicação:

```console
dotnet run
```

Acesse o endereço local informado pelo terminal para visualizar a aplicação.

## Objetivo

Projeto desenvolvido para explorar o desenvolvimento de aplicações web com C# e Blazor, trabalhando com componentes reutilizáveis, gerenciamento de estado, injeção de dependências e construção de interfaces interativas utilizando MudBlazor.
